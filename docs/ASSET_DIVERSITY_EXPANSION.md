# 硬装资产多样性扩展计划

本计划只扩展活动住宅 `house_spacious_yunkuo_135_v4` 的五类硬装资产，不增加或重做 `reference_only` 家具，不修改 55 个稳定设计目标，也不把铺法复制成新的材质资产。

## 1. 目标

起点 87 个资产中有 60 个墙漆参数变体。扩展的重点不是继续增加近似色，而是补齐能改变完整方案气质的墙纸、地板、瓷砖和吊顶。实际完成两轮共 27 个高差异资产：

- 第一批：墙纸 4、木地板 3、瓷砖 5，共 12 个材质资产；
- D1 第二轮：墙纸 3、木地板 3、瓷砖 5、吊顶 4，共 15 个资产/几何预设。

两轮完成后，目录由 87 个扩展到 114 个。第一轮完成后为 99 个；最终为墙漆 60、墙纸 15、地板 12、瓷砖 18、吊顶 9。

## 2. 设计空间

资产共同覆盖八个风格方向，而不是形成八套不可互换的固定套餐：明亮北欧、原木自然 / Japandi、侘寂自然、复古现代 / 中古、现代东方、南法 / 地中海、Art Deco / 现代古典、深色当代 / 折衷主义。

约三分之一资产承担明确的风格锚点，其余作为能跨两个以上方向使用的桥接资产。每个资产至少要能进入三套跨品类组合，不能只服务一张效果图。

## 4. 同资产跨墙面一致性硬门禁

“相同资产”由稳定 `asset_id` 定义。它应用到不同朝向墙面时，必须保持同一印刷色、釉色或材料色号感，只允许存在能说明墙角、凹凸和光源方向的克制受光变化。

必须保持一致：

- Base Color 使用相同 sRGB 贴图、相同色彩空间和相同校准参数；
- 米制 UV 的真实尺寸、旋转规则和对花方式一致；
- Normal、Roughness、sheen、环境反射强度和贴图版本一致；
- 同一 `asset_id` 共用缓存贴图，不能按墙面重新随机生成材质；
- 东、西、南、北向墙面不能出现像换了色号的整体明暗或色相漂移。

允许变化：方向光产生的轻微明暗、釉面或压纹随视角变化的高光，以及墙角、洞口和微表面的正常遮蔽与接触阴影。

自动与视觉验收：

1. 结构测试锁定墙漆、墙纸以及墙用瓷砖的显示校准和贴图复用；
2. 运行时把同一资产同时赋给至少两面互相垂直的墙；
3. 在固定曝光和白平衡下采集正视墙心区域，排除边角阴影和镜面高光；
4. 比较平均明度和综合色相，不允许达到“另一色号”的程度；
5. 再用斜视近景确认 Normal、Roughness 和墙角转折仍然可读，防止通过完全自发光伪造一致性。

任何新增墙纸或可上墙瓷砖未通过上述门禁，不得进入正式目录。

## 5. 生产与集成

1. 每个 ImageGen 基础图单独生成并保存完整提示词；
2. 项目脚本确定性无缝化，派生 Base Color、OpenGL Normal、Roughness 和 Height；
3. 4K 文件是工程派生母版，不描述为扫描材质或模型原生 4K；
4. 运行时只发布优化贴图与缩略图，并继续按需加载；
5. 更新目录、资产清单、资产卡、Blender 隐藏资产库和前端计数；
6. 运行目录、接缝、物理尺度、跨墙一致性、Scheme、Blender/GLB 和前端构建测试。

## 6. 主要失败方式

- 只换颜色、没有增加新的材料或图案角色；
- 生成图自带方向光、透视或高光，导致 PBR 重复计算光照；
- 强墙纸、强花砖和高色差木纹同时抢焦点；
- 将棋盘、人字等铺法重复编码成多个材质，破坏 Scheme 职责；
- 用过高自发光消除所有受光变化，使墙面像屏幕或贴纸；
- 新资源全部进入首屏，造成纹理负载和显存回归；
- 使用可识别品牌、艺术家或历史图案的近似复制。
